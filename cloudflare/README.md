# 検索サービス

[株主優待券が使えるお店検索](https://yutai-quo-navi.github.io/yutai-map/)

外食・宿泊の検索・件数・ページ送り・ブランド一覧は、非公開R2の位置インデックスをWorkerで参照します。検索時のD1読み取り・外部店舗検索はありません。地点候補の入力補助はOpenPOI suggestを利用します。

D1は店舗収集の管理元と定期インデックス生成に使用します。宿泊の `feature_snapshots` も事前バッチの元データとして保持します。旧 `/v1/features/` 一覧APIとD1キャッシュ補助コードは廃止し、検索WorkerからD1への参照はありません。D1設定は既存の保守CLIが同じ設定ファイルを参照するため残します。

`wrangler.toml.example` は本番と同じバインディング構成を保ちます。R2バケットは非公開のまま使用し、インデックスの公開ダウンロード経路は設けません。外食・宿泊とも初回30件と追加1回の最大60件を返し、全件数は別に計算します。

廃止した `issuer_search_config` は新規スキーマ・更新処理から除外しています。既存D1内のテーブル自体は削除していません。
