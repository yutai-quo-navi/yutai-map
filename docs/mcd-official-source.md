# マクドナルドの公式店舗情報

店舗情報と座標はマクドナルド公式店舗検索が使用するAPIを取得元とする。
収集・検証・月次差分同期は非公開リポジトリ `yutai-data-private` の
`tools/collect_mcd.py`、`tools/sync_mcd.py`、`.github/workflows/mcd.yml` で管理する。
全国店舗一覧・生成SQLは公開リポジトリへ保存しない。

本番D1への初回登録と公式ID・座標を使った近隣検索の検証が成功した後に、
`data/issuers/mcd/config.json` を `official_coordinates` に切り替える。
既存の共通検索処理がD1の店舗検索APIへ振り分けるため、OpenPOIの名前照合や
座標取得はマクドナルドの検索に使用しなくなる。

店舗別の株主優待利用可否は公式APIに提供されていない。
公式IRの「一部利用できない店舗あり」および注文方法の制限を案内に残し、
公式店舗掲載をもって全店の優待利用を保証しない。

定期更新は毎月2日07:40 JST。公式一覧と地域別取得の一致、47都道府県の収録、
店舗数・差分・座標・地域減少を検証し、不完全な取得は本番へ反映しない。
変更なしの通常更新はmanifestと集計行だけを読む。変更店舗のみ登録・削除し、
本番D1の読み書き実測値は非公開ワークフローの実行結果に記録する。

公開ガイドは既存の設定変更トリガーと毎日のガイド生成により店舗集計を取り込む。
公開ガイドの生成は店舗全件を読まず、集計情報だけを使う。
