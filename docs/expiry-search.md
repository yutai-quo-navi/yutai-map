# 失効検索

期限シートの確認済みレコードを店舗検索への登録有無によらず掲載。日本時間で失効済みの行は非表示。7日以内を分類横断で先頭にまとめ、8〜60日は分類別、61日以降は下部の折りたたみに表示。重複表示しない。残日数を左端に大きく表示し、3日以内は赤地・白文字、7日以内は赤文字。それ以外はグレー。上部の外食・宿泊・失効タブは共通の配色を維持する。

「持ってる」は既存の `yutai-expiry-holdings-v1` を維持。通知日は全券共通の `yutai-expiry-alert-days-v1` に当日・1・2・3日前の複数選択を保存し、初期値は全日。旧個別日設定より共通設定を優先する。通知は指定日にサイトを開いている画面上だけに表示。端末間同期・プッシュ通知はない。券ごとの管理IDで設定を保持するため、翌年の別IDには所有を自動継承しない。日付不明は月表示のみでアラート対象外。消化済み操作は不要。

まとめて登録は端末内で、期限DBのコード・会社名と貼り付けテキストを照合。全角英数字、スペース・カンマ・改行区切り、HD表記を正規化する。コードのみの一覧か、会社名が合致する証券会社の行を認識。混在する数値列はコードだけを根拠に登録しない。未登録・不一致のコードは別表示する。確認ボタンで現在掲載中の未失効の該当券のみ一括追加し、既存選択は維持。株価・損益を含む生テキストは送信・永続保存しない。期限DBにない銘柄の期限は推定しない。

## シートからの取り込み

認証済みGoogle Drive接続で`yutai-expiry`の「期限DB」を範囲読み取りし、ヘッダーを含む全行を `{"values":[...]}` として一時保存する。非公開シートの共有設定は変更しない。

```sh
python tools/sync_expiry_sheet.py /tmp/sheet-values.json --checked-on YYYY-MM-DD
python tools/build_expiry.py --baseline /tmp/previous-master.csv --draft /tmp/expiry-draft.txt
python tools/build_expiry.py --check --draft /tmp/expiry-draft.txt
```

取り込みは列名・日付・ID・重複・会社対応を検証してからCSVを更新する。シートから消えた統合前の行は履歴として残し、確認待ちにして旧期限の再掲載を防ぐ。日付未入力時に月末を補完しない。

CSVと生成JSON、同期ハッシュを同時に反映し、既存のGitHub Pages構築で公開する。変更がなければコミットしない。同期ハッシュは読み取り値のJSONをUTF-8、ensure_ascii=False、separators=(',', ':')で直列化したSHA256。
