# 王将フードサービス・ジョイフルの店舗検索

2026-10-13に公式情報とD1を照合し、王将系727店舗（餃子の王将723・GYOZA OHSHO4）とジョイフル608店舗を公開しました。

優待利用条件は [王将の公式FAQ](https://ir.ohsho.co.jp/ir/faq/) と [ジョイフルの公式優待情報](https://corporate.joyfull.co.jp/ir-complimentary) を参照します。JoyNaho、喜楽や・並木街珈琲・二五十・キッチンジローは今回の店舗取得元では未掲載です。

収集プログラム・検証テスト・D1差分同期・月次更新は、非公開の `yutai-quo-navi/yutai-data-private` の `pipelines/ohsho-joyfull` と `ohsho-joyfull.yml` で運用します。公開アプリは引き続き同じD1を検索します。公開設定、既存の検索とガイド、ほかの会社の収集処理は維持します。

今後の新規ブランド追加は、原則としてプライベート側に収集処理と自動更新を実装して運用を開始します。方針は両リポジトリのAGENTS.mdに記録しています。
