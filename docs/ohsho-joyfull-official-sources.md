# 王将フードサービス・ジョイフルの公式店舗情報

## 優待対象と掲載範囲

- 王将（9936）: https://ir.ohsho.co.jp/ir/faq/ に国内の餃子の王将、GYOZA OHSHO、JoyNahoの飲食・持ち帰りが優待電子チケット対象と明記。大阪王将は含めない。公式全国一覧で取得できるのは餃子の王将・GYOZA OHSHOの727店舗で、JoyNahoは現在未掲載。
- ジョイフル（9942）: https://corporate.joyfull.co.jp/ir-complimentary に全国のジョイフルが対象と明記。喜楽や・並木街珈琲・二五十・キッチンジローも対象だが、今回の店舗取得元はジョイフル本体のみ。フレンドリーは対象外。

## 店舗取得元

- 王将: https://www.ohsho.co.jp/shop/ が案内する公式 https://map.ohsho.co.jp/b/ohsho/attr/?srt=citycode,poi_name_yomi を20件ずつ取得。毎ページの総件数、表示範囲、件数、全店舗IDの一意性を確認する。各店舗のLocalBusiness構造化データから住所、電話、世界測地系の座標を取得し、公式一覧と詳細のID・名称を照合する。`infoJSON`とルートリンクの座標は日本測地系のため使用しない。掲載開始が未来の店舗は除外する。
- ジョイフル: https://www.joyfull.co.jp/shop の公式地域リンク（1〜9）を列挙。各地域の公式表示件数と取得件数を照合し、地域をまたぐ重複IDを拒否する。公式HTMLの`data-latitude`・`data-longitude`と住所・店舗IDを使用。地域一覧に電話番号はないため空欄とする。

## 公開・継続更新

`scrape_ohsho_joyfull.yml` は毎月4日06:15 UTCとソース変更時に実行。D1の前回スナップショットを復元し、追加・削除・変更のみ同期する。全件データとSQLは公開リポジトリに保存しない。
